# AI-Powered Smart Analysis Dashboard

## Project Overview
The AI-Powered Smart Analysis Dashboard is a web-based application that uses Artificial Intelligence to analyse text, images, and speech through a simple and interactive dashboard.

## Main Features
1. **Sentiment Analysis:** Identifies whether text expresses positive, negative, or neutral sentiment.
2. **Image Classification:** Predicts the contents of uploaded images using a pre-trained AI model.
3. **Speech Recognition:** Converts spoken words into text.
4. **Interactive Dashboard:** Displays analysis results, prediction history, and statistics.
5. **User Authentication:** Allows users to register and log in.
